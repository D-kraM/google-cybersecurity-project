# Cybersecurity Incident Report: SYN Flood Attack

## Incident Identification
An alert from the monitoring system indicated a problem with the web server. Analysis of the captured data packets transiting to and from the server revealed a flood of incomplete TCP connection requests. The logs show multiple TCP connections failing to establish. This is characteristic of a SYN flood attack, which aims to overwhelm the server and cause a Denial of Service (DoS) for the agency.

## Attack Analysis and Impact
A SYN flood attack abuses the standard TCP three-way handshake. Normally, a client requests a connection with a SYN packet, the server acknowledges it with a SYN-ACK, and the client finishes with an ACK. However, in this incident, the malicious actor (originating from the external IP 203.0.113.0, as seen in log lines 52-54) flooded the server with SYN requests but never sent the final ACK to complete the handshake. 

This resulted in a massive number of 'half-open' connections that exhausted the web server's resources. Because the server's load was completely overwhelmed by this abnormal traffic, legitimate clients and employees were denied access to the website, rendering the travel agency unable to continue its normal sales operations.
