# Security Incident Report

## Section 1: Identify the Network Protocol Involved in the Incident
**Network Protocols Identified:**
* **DNS (Domain Name System - Application Layer):** Used to resolve domain names (`yummyrecipesforme.com` and `greatrecipesforme.com`) to their respective IP addresses, enabling initial connection and subsequent redirection[cite: 1].
* **HTTP (Hypertext Transfer Protocol - Application Layer):** Used to request web page content, execute injected client-side JavaScript, and transfer the malicious executable download[cite: 1].

*Note: Both protocols were identified and verified using the tcpdump packet capture log[cite: 1].*

---

## Section 2: Document the Incident
* **Initial Access:** A former employee executed a successful brute-force attack against the web host's administrative panel over HTTP by exploiting unchanged default administrative credentials[cite: 1].
* **Persistence & Tampering:** Upon gaining access, the attacker changed the administrative account password to lock out authorized personnel[cite: 1]. The attacker then modified the source code of `yummyrecipesforme.com` by embedding malicious JavaScript[cite: 1].
* **Execution & Impact:** When customers visited the site, the injected JavaScript prompted them to download an executable file disguised as a browser update[cite: 1]. Running this file executed a script that redirected the victim's browser to an unauthorized replica site (`greatrecipesforme.com` / `192.0.2.17`), which infected client machines with malware[cite: 1].
* **Discovery:** The incident was identified following customer helpdesk complaints regarding browser slowness and unexpected downloads, and was subsequently confirmed through sandbox testing and tcpdump log analysis[cite: 1].

---

## Section 3: Recommend Remediation for Brute Force Attacks
* **Recommended Security Action:** Enforce Two-Factor Authentication (2FA) on all administrative accounts and control panel logins[cite: 1].
* **Justification:** Implementing 2FA adds a mandatory secondary layer of security (such as an authenticator app code or OTP)[cite: 1]. Even if an attacker successfully guesses or brute-forces administrative passwords—or exploits unmanaged default credentials—they cannot gain access without the physical second factor[cite: 1]. This effectively neutralizes single-factor credential exploitation and prevents unauthorized access to the web host[cite: 1].
