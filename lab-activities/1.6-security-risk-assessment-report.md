# Security Risk Assessment Report

## Part 1: Select up to three hardening tools and methods to implement

### Recommended Hardening Tools and Methods

1. **Password policies**
   - Account lockout policy after a specified number of failed login attempts.
   - 6 months expiration of password.
   - Standard password format with lowercase, uppercase, symbols, and alphanumeric limitations.
   - Mandate to change the default password of the database admin credentials.

2. **Firewall maintenance**
   - Continuous configuration and monitoring.

3. **Multifactor Authentication (MFA)**
   - Requiring One-Time Passwords (OTP) or Authenticator apps.

---

## Part 2: Explain your recommendations

Based on the recent breach assessment, four major vulnerabilities were identified that require immediate hardening.

* **Password policies** will standardize, guide, and enforce rules for employee accounts, especially admin or elevated accounts, and require mandatory changes to default database admin credentials. They adhere to NIST standards, preventing unauthorized access through brute force or credential sharing.
* **Firewall maintenance** should be conducted daily, weekly, monthly, and yearly depending on the depth of configuration required, which includes continuously updating the list of suspicious IP addresses to be blocked and denied.
* **Multifactor Authentication (MFA)**: Since the company already has MFA available, it should be fully deployed to layer protection onto every employee's account. This blocks unauthorized access even if passwords are leaked. Because secondary verification (like phone applications or OTPs) cannot be easily shared, attackers cannot proceed with brute-force or credential-stuffing attacks.
