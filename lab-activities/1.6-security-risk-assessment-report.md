# 1.6 Security Risk Assessment Report: System & Network Hardening

## Overview
Following a comprehensive security review and breach assessment, critical vulnerabilities were identified across authentication mechanisms and network perimeter defenses. This report outlines three prioritized hardening tools and methods to mitigate unauthorized access, credential exploitation, and external network intrusions.

---

## Part 1: Recommended Hardening Tools & Methods

| # | Hardening Tool / Method | Technical Implementation Scope |
| :--- | :--- | :--- |
| **1** | **Password Policies** | <ul><li><b>Account Lockout:</b> Enforce account lockout thresholds after a specified number of consecutive failed login attempts to prevent brute-force attacks.</li><li><b>Complexity Standards:</b> Require robust passphrase standards including uppercase, lowercase, numbers, and special characters.</li><li><b>Credential Rotation:</b> Mandate password expiration intervals (e.g., every 90–180 days).</li><li><b>Default Credential Remediation:</b> Enforce an immediate mandatory change of all default administrative database credentials.</li></ul> |
| **2** | **Multi-Factor Authentication (MFA)** | <ul><li><b>Mandatory Deployment:</b> Fully deploy MFA across all employee, administrative, and remote access accounts.</li><li><b>Time-Based Verification:</b> Implement authenticator applications (TOTP) or hardware tokens to eliminate reliance on single-factor passwords.</li></ul> |
| **3** | **Firewall Maintenance & Hardening** | <ul><li><b>Rule Optimization:</b> Establish continuous review schedules (daily/weekly monitoring, monthly rule audits) to eliminate stale or overly permissive rules.</li><li><b>Traffic Filtering:</b> Dynamically update blacklist/whitelist policies to block malicious and unverified IP addresses at the perimeter.</li></ul> |

---

## Part 2: Justification & Strategic Impact

### 1. Password Policies
Weak and default credentials represent an immediate entry vector for unauthorized threat actors. Implementing strict password policies directly addresses default administrative database exposures and credential reuse. Combined with account lockout thresholds, these policies effectively eliminate automated dictionary and brute-force attacks while aligning identity management with NIST SP 800-63 guidelines.

### 2. Multi-Factor Authentication (MFA)
Because the organization already possesses MFA infrastructure, activating it across all user endpoints creates defense-in-depth for access control. Even if user credentials are compromised through phishing or database leaks, threat actors cannot authenticate without possession of the secondary verification token, effectively neutralizing credential-stuffing campaigns.

### 3. Firewall Maintenance
A firewall is only as effective as its active configuration. Establishing structured maintenance routines ensures that firewall rules adapt to evolving threat intelligence. Regular auditing prevents configuration drift, restricts unnecessary inbound ports, and ensures malicious source IPs are dropped before reaching internal network services.
