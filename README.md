# Google Cybersecurity Professional Certificate Portfolio

Welcome to my cybersecurity portfolio! This repository contains all of my practical lab activities, incident reports, and module certificates completed during the **Google Cybersecurity Professional Certificate** program.

## 🎯 Objective
To showcase my practical skills in threat intelligence, network security, and incident response through hands-on labs, audits, and real-world simulated scenarios.

## 🛠️ Skills & Tools Demonstrated
*   **Incident Response:** Playbooks, NIST Cybersecurity Framework, Incident Reporting
*   **Network Security:** Packet analysis, tcpdump, Wireshark, IDS/IPS
*   **Security Information and Event Management (SIEM):** Chronicle, Splunk
*   **Scripting & Querying:** Python, SQL, Linux command line
*   **Risk Management:** Audits, Compliance (PCI DSS, GDPR), Risk Assessment
